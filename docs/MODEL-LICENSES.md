# Optional model references

Ink does not bundle these model weights in the source archive. The app can download them only when the user explicitly installs the corresponding optional pack.

## Arabic Dialect Speech Pack

- Runtime/export: `OpenVoiceOS/whisper-large-v3-turbo-arabic-dialectal-v2-onnx`
- Source fine-tune: `oddadmix/whisper-large-v3-turbo-arabic-dialectal-v2`
- Base: `openai/whisper-large-v3-turbo`
- License reported by the export and source model cards: Apache-2.0

Always review the upstream model cards and licenses before redistributing model weights with a packaged release.
